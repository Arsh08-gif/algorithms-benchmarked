# Algorithm Benchmark

A growing collection of classic algorithms implemented and analyzed across multiple approaches — comparing time and space complexity with real benchmarks and visualizations.

Each algorithm is implemented in multiple ways (brute force → optimized) with:
- Measured runtime across increasing input sizes
- Theoretical space complexity visualized as input scales
- Charts generated with matplotlib

## Algorithms
0/1 Knapsack 

## Structure

```
algorithm-benchmark/
└── each algorithm in its own folder
```

## Requirements

```bash
pip install matplotlib
```

## Run

```bash
cd <algorithm_folder>
python3 <algorithm>.py
```
